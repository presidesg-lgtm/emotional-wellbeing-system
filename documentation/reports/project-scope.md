# Project Scope and Feature Priority

## Priority 1 — Core System

- User registration
- User login and logout
- User profile
- Text mood-entry submission
- Machine-learning emotion classification
- Prediction confidence
- Safe supportive feedback
- Mood-entry storage
- Mood-history page
- Mood dashboard
- Administrator login
- Administrator user management
- Model evaluation and technical documentation

## Priority 2 — Proposal Supporting Features

- Counsellor profiles
- Counsellor availability
- Appointment booking
- Appointment administration
- Payment-proof submission
- Payment verification

## Priority 3 — Extended Features

- Community forum
- Forum moderation
- Administrative analytical reports
- Automated appointment reminders
- Advanced transformer model comparison

## Excluded from the Current Academic Prototype

- Clinical diagnosis
- Automatic treatment recommendations
- Emergency-service replacement
- Real financial transactions
- Unrestricted access to private emotional entries
- Automatic retraining using live user data
- Video counselling
- Real-time private messaging
