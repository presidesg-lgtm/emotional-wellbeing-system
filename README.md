# Text-Based Emotional Wellbeing Analysis System

## Project Overview

This final-year project develops a web-based emotional wellbeing
analysis system using machine learning and natural language processing.

Users will be able to submit text describing their emotional state.
The trained machine-learning model will analyse the text, classify the
expressed emotion, and present supportive feedback and mood trends.

The system is intended to support emotional self-awareness. It is not
a clinical diagnostic tool and does not replace professional mental
healthcare.
