Controlled update workflow

Transformer retraining is intentionally performed outside the web request process. The administrator prepares privacy-reduced candidate data, evaluates the resulting model, registers the local model directory, and explicitly activates only an evaluated model. This avoids automatically replacing the validated model with unreviewed user data.
